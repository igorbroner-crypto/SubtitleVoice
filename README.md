# Subtitle Voice 1.13 — только озвучка по субтитрам

Интерфейс разделён на три вкладки:

- **Общее** — окно захвата камеры, сразу под ним запуск/пауза распознавания, затем переключатель «Переводить на русский», ниже сворачиваемые **«Настройки рамки и камеры»** (ориентация, приближение, фильтр, ширина/высота/высота положения рамки). Ниже статус и последняя распознанная реплика.
- **Голоса** — выбор Android TTS-движка, мужского и женского русских голосов, проверка голосов и скорость озвучки. Если голос персонажа не указан — мужской по умолчанию.
- **Игры** — выбор/создание/удаление профиля игры, мужские и женские персонажи через запятую, ручной поиск персонажей в Wikidata и их сохранение. Поиск по команде пользователя требует интернета только в момент импорта.

Удалено: режим микрофона, его разрешение Android, распознавание голоса по высоте тона, показ обрезанного OCR-кадра, лишние подписи, неиспользуемый код платного онлайн-перевода.

Сохранены: английский ML Kit OCR с локальным переводом на русский при **включённом** переключателе; русский Tesseract OCR и прямая озвучка без перевода при **выключенном** переключателе; защита от повторов, ориентация, масштаб камеры, профили, словарь имён и выбор офлайн TTS.

Добавлена защита от перекрытия системными кнопками навигации Android через обработку `WindowInsetsCompat`, а также прокрутка настроек при малой высоте экрана.

## Обновление GitHub

Заменить 3 файла в том же пути:

1. `app/src/main/java/kz/subtitlevoice/MainActivity.java`
2. `app/src/main/AndroidManifest.xml`
3. `app/build.gradle`

Запустить сборку в GitHub Actions. Файл APK собирается GitHub, он не включён в этот архив. Сборка и работа на физическом телефоне в данной среде пока не проверены.
