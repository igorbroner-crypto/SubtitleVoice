# Subtitle Voice — Android

Прототип озвучивания игровых субтитров с экрана телевизора через камеру Android-телефона.

## Возможности
- Обработка **только настраиваемой прямоугольной области** по центру нижней части изображения с камеры.
- Распознавание латинского текста на устройстве, с фильтрацией повторов и случайного OCR-шума (2 одинаковых кадра).
- Опциональный **английский → русский** перевод моделью ML Kit на устройстве (скачивание модели при первом запуске).
- Озвучка Android TextToSpeech с регулировкой скорости **0,70–2,00×**.
- Два выбираемых профиля голосов и выбор профиля по умолчанию. Пол голоса определяется пользователем на слух: Android TTS не предоставляет достоверного признака пола.
- Сопоставление по меткам персонажей вида `Маша: Привет` или `Vasya: Hello`. Для каждого имени назначается мужской или женский профиль.
- При новых репликах прежняя озвучка прерывается.

## Ограничения
- **Это проект, а не готовый проверенный APK**. APK собирается в Android Studio или в GitHub Actions.
- ML Kit Text Recognition v2 Latin не гарантирует распознавание кириллицы. Основной сценарий: **английские субтитры с переводом на русский**. Для русского OCR понадобится иной движок.
- Без префикса с именем говорящего нельзя достоверно определить, кто произносит фразу. В таком случае используется голос по умолчанию.
- Для разных тембров должны быть доступны разные русские голоса в системном TTS Android; на некоторых телефонах установлен один голос.
- Скорость зависит от камеры, качества изображения, OCR и переводчика: озвучка не может начинаться раньше появления распознаваемой надписи.
- Сопоставление рамки работает по изображению предварительного просмотра; важна стабильная установка телефона на штатив.

## Как собрать APK
1. Откройте папку проекта в Android Studio (JDK 17, Android SDK 35).
2. Дождитесь синхронизации Gradle, запустите `Build > Build APK(s)`.
3. APK: `app/build/outputs/apk/debug/app-debug.apk`.

**Или GitHub:** загрузите содержимое папки в репозиторий GitHub, запустите `Actions > Build Android APK > Run workflow`. Скачайте артефакт `SubtitleVoice-debug-apk` и установите APK на телефон.

## Проверка
Проверяйте в первую очередь английские субтитры с именами (`Masha: Hello`), точность рамки, задержку на конкретном устройстве и доступность русских голосов. Проект не компилировался в текущей среде из-за отсутствия Android SDK.
