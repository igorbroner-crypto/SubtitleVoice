# Subtitle Voice 1.11 — исправление русского OCR

В режиме камеры переключатель **«Переводить на русский»** полностью управляет языком:

- ВКЛ: английские субтитры → ML Kit Latin OCR → локальный английский→русский перевод → озвучка.
- ВЫКЛ: русские субтитры → Tesseract Russian OCR → **без вызова переводчика** → озвучка русским голосом.

**Не используется автоопределение языка.** Для русского OCR применяется бесплатная модель `tessdata_fast/rus.traineddata`; Gradle скачивает её **во время сборки APK** с официального репозитория Tesseract и включает внутрь APK. На телефоне приложение не скачивает русскую OCR-модель и не отправляет кадры или текст на сервер. После установки распознавание кириллицы работает локально. Зависимость Tesseract4Android берётся из JitPack при сборке.

В аудиорежиме выключенный перевод выбирает `ru-RU`, включённый — `en-US`; Android SpeechRecognizer может зависеть от установленного локального движка и не гарантирует офлайн без такого движка.

## Как обновить GitHub

В существующем репозитории замени **три файла**:

1. `app/src/main/java/kz/subtitlevoice/MainActivity.java`
2. `app/build.gradle`
3. `settings.gradle`

Другие файлы замены не требуют. Сборка запускается автоматически по commit. Загрузчик Tesseract-модели в `app/build.gradle` выполняется на GitHub Actions, поэтому загружать `.traineddata` в репозиторий НЕ нужно.

## Что проверить после установки

Отключи переключатель «Переводить на русский», наведи рамку на русскую фразу. Строка OCR должна отображать текст кириллицей, а не латиницей. При включённом переключателе распознавание и перевод английских субтитров остались прежними. Ожидается, что Tesseract будет медленнее ML Kit на некоторых телефонах; скорость и точность на устройстве не проверены.

Сборка APK здесь не выполнялась: Android SDK в текущей среде отсутствует. Если GitHub Actions покажет ошибку, нужен лог сборки.
